# Garments Factory Intelligence System (GFIS)

**AI-Powered Production, Profitability & Decision Intelligence for Apparel Manufacturing**

> ⚠️ **Status:** In active development (v0.1). Demo uses **synthetic data only**.

## What this is

GFIS turns factory data into decisions: daily production tracking, profit analysis, 
quality, inventory, order delivery risk, root-cause investigation, and forecasting — 
all in one dashboard.
